Subscription vs API

Is a subscription cheaper than paying per token?

A plan costs a flat price a month. The API charges for every run, and a run costs more than its token count suggests because each step re-sends the whole context. This page turns a plan price into the number of agent runs it has to beat.

Questions

How many agent runs does a Claude Max plan have to beat?
Divide the plan price by the cost of one run at API rates. On the default workload (12 steps, Claude Sonnet 5.5, 10% retries, no caching) a run costs $0.351, so Max 5x at $100 a month equals 285 runs a month, about 9.5 a day, and Max 20x at $200 equals 570 runs, about 19 a day. With a 90% cache hit rate a run costs $0.096 and the same $100 buys about 1,040 runs, or 35 a day. If your plan lets you run more than that, the plan is the cheaper route.
Why can't this tell me whether my plan covers my usage?
Plans publish their usage limits only in relative terms. Anthropic describes Max as 5x or 20x more usage than Pro and gives no token or message count, and the limits are shared between chat and Claude Code. With no published quota there is nothing to compare against. The page gives the number of runs your plan price buys at API rates and leaves the comparison with your own usage meter to you.
